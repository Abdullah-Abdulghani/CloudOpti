## 📊 CloudOpti - Cloud Cost Optimization SaaS Prototype

**CloudOpti** is a prototype cloud monitoring and cost optimization platform built to explore cloud cost visibility, infrastructure monitoring, and optimization workflows using modern web technologies.

> **Note:**  
> This project is currently a prototype/demo platform created for learning, experimentation, and portfolio purposes.  
> The data, scenarios, and optimization results shown in this project are illustrative and should not be treated as production outcomes, verified customer results, or commercial traction.

---

## 🎯 The Problem

Cloud teams often face challenges in understanding how infrastructure resources are being used and how usage patterns may affect cost.

Common challenges include:

- Unused or underutilized cloud resources that may increase operational costs.
- Limited visibility into CPU, RAM, and estimated cost in one clear dashboard.
- Manual review processes that are time-consuming and difficult to repeat consistently.
- Delayed decisions when monitoring and cost signals are not presented clearly.

---

## 🚀 Prototype Solution

CloudOpti explores a full-stack workflow for monitoring cloud-like resource data and presenting possible optimization opportunities through a SaaS-style dashboard.

Key prototype features include:

- **Resource Monitoring:** Displaying CPU, RAM, estimated cost, and system health indicators.
- **Detection Logic:** Identifying potentially idle or underutilized resources using demo rules and simulated metrics.
- **Optimization Workflow:** Demonstrating how a user could review flagged resources and simulate an optimization action.
- **Dashboard Visualization:** Presenting usage trends, alerts, and cost-related insights in a clean interface.

---

## 📈 Prototype Evaluation

This project does not claim real customers, verified savings, revenue, or production deployment.

Instead, the prototype demonstrates:

- A dashboard-based workflow for cloud resource visibility.
- Simulated monitoring data for explaining cost and performance patterns.
- Rule-based detection of resources that may require review.
- Illustrative optimization scenarios for portfolio and technical demonstration purposes.
- A scalable concept that could later be extended toward real cloud integrations.

---

## 🛠 Tech Stack

- **Frontend:** React 19, Recharts, Tailwind CSS 4.
- **Backend / Agent:** Python, `psutil`, Firebase REST API.
- **Database:** Firebase Realtime Database.
- **Algorithms / Logic:** Threshold-based detection, statistical analysis concepts, anomaly detection concept, cost forecasting concept.

---

## 💼 Prototype Scope

CloudOpti is currently a **Proof of Concept**, not a commercial SaaS product.

Current scope:

- Demo dashboard interface.
- Simulated or experimental monitoring data.
- Prototype resource classification logic.
- Illustrative cost estimation workflow.
- Portfolio-ready case study and presentation materials.

Not included at this stage:

- No real customers.
- No verified production savings.
- No active paid plans.
